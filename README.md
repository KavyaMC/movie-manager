# Movie Collection Manager

## Overview

Movie Collection Manager is a browser-based movie collection application built with HTML, Bootstrap, and vanilla JavaScript.

The project allows users to add and manage movies while practicing a more structured approach to handling application data. Movie information is stored separately from the page and displayed through the interface as needed.

## Description

The application provides a simple way to maintain a personal movie collection. Users can add movie details, update their watched status, edit titles, and manage the collection using search, sorting, and filtering options.

The project builds on concepts introduced in earlier JavaScript exercises while introducing the use of structured movie data stored in an array.

## Purpose

The purpose of this project is to practice building a small interactive web application using vanilla JavaScript while working with a collection of related data.

It focuses on:

- Managing multiple pieces of information for each movie
- Using JavaScript objects and arrays
- Working with search, sorting, and filtering
- Updating the interface when information changes
- Building an accessible and keyboard-friendly interface

## Features

The application includes:

- Add new movies
- Delete movies
- Mark movies as watched or unwatched
- Edit movie titles
- Search by title or director
- Sort by title, release year, or rating
- Filter by watched status
- View total, watched, and unwatched movie counts

Each movie includes:

- Title
- Director
- Release year
- Genre
- Personal rating
- Watched status

## Accessibility

Accessibility is considered throughout the interface.

The project uses semantic HTML, clearly associated form labels, native form controls, and keyboard-accessible buttons and inputs. Focus is also managed after actions such as adding a movie.

Live regions are used for the collection statistics so that changes can be communicated to screen readers.

## Technology

The project is built with:

- HTML5 for the page structure
- Vanilla JavaScript for application logic and interaction
- Bootstrap 5.3.8 for layout and styling
- Standard browser DOM APIs and events

## Conclusion

Movie Collection Manager is a practical step toward working with structured application data in frontend development. It combines familiar JavaScript concepts with a more organized way of managing a collection.

The project provides hands-on practice with interactive interfaces, array-based data, user input, and accessibility while keeping the implementation simple and framework-free.
